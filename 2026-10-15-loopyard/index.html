Loopyard

2026-10-15 · all games

Tap a truck: its last block breaks into cubes that ride the belt to a truck that takes them. Deliver every load before the belt is full. 15 levels, each on its own loop, with lessons, lives and coins.

Web (three.js)

Play in the browser

Chrome, Safari, Edge or Firefox. Downloaded instead: double-click Play offline (Windows).bat or Play offline (Mac).command in the web folder — a browser does not run the game straight from index.html.

Windows

Download Loopyard-Windows.zip

  1. Extract the zip (right-click → Extract All…).
  2. Double-click Loopyard.exe in the Loopyard folder (the whole folder is needed).
  3. If Windows says “Windows protected your PC”: More info → Run anyway.

Mac (Apple silicon and Intel)

Download Loopyard-Mac.zip

  1. Double-click the zip: a Loopyard-Mac folder appears.
  2. Double-click Run perf test.command first: it prepares the app for this Mac and measures the frame rate.
  3. Double-click Loopyard.app to play. Details: READ ME FIRST.txt in the folder.
