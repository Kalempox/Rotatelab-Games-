# Rotatelab Games

Every game we make, in a folder named `<date>-<name>`, with its working builds:

- **web** — the three.js version, played in the browser (GitHub Pages);
- **windows** — the Unity player for Windows (zip);
- **mac** — the Unity player for macOS, Apple silicon and Intel (zip, with a one-click frame-rate test).
